# 도전! 일본어 동사 て형

파스텔 토끼 캐릭터와 함께하는 한국어 안내 4지선다형 일본어 게임입니다.
외부 API, 폰트, 이미지, 로그인 없이 동작합니다.

## 바로 플레이하기

빌드된 **`dist/game.html`을 내려받아 브라우저에서 열면 됩니다.**
이 파일 하나에 HTML, CSS, JavaScript와 모든 문제가 포함되어 있어 인터넷과 서버가 필요 없습니다.
게임 안 오른쪽 위의 **↓ HTML 다운로드** 버튼으로도 단일 파일을 저장할 수 있습니다. 저장된 파일을 브라우저에서 열면 시작 화면으로 돌아옵니다.
채팅/문서 미리보기 대신 내려받은 HTML을 Chrome 또는 Edge로 여세요. 미리보기 서비스가 JavaScript나 다운로드를 차단하는 경우에는 그 안에서 게임을 실행할 수 없습니다.
파일을 직접 수정할 때는 아래 원본 파일을 수정하고 다시 빌드하세요.

## 개발 실행

Python 3가 있으면 저장소 폴더에서 실행합니다.

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

자신의 PC에서 실행했다면 브라우저 주소창에 `http://localhost:8000`을 입력하세요.
클라우드 서버의 localhost는 자신의 PC 주소와 다릅니다. 클라우드에서 바로 확인할 공개 미리보기 주소는 제공하지 않으므로 단일 HTML 파일을 내려받아 여는 방법을 사용하세요.

Node.js가 있다면 `npm start`도 같은 서버를 실행합니다(Python 3 필요).
원본 `index.html`은 JavaScript 모듈을 불러오므로 파일을 더블클릭하지 말고 HTTP 서버로 여세요.

## 게임 방법

1. 10문제 또는 전체 13문제를 선택합니다. 10문제는 13개 중 중복 없이 무작위 출제합니다.
2. 문제별 시간 제한 없음 / 10초 / 20초 / 30초를 선택합니다.
3. 네 보기 중 하나를 누르거나 숫자 키 1–4로 답합니다.
4. 정답은 초록색과 꽃 효과, 오답은 분홍색과 흔들림 효과로 표시됩니다. 모션 감소 설정을 존중합니다.
5. 해설을 확인한 뒤 다음 문제로 이동합니다. 시간은 새 문제마다 초기화되며 해설 중에는 멈춥니다.
6. 결과 화면에서 100점 기준 점수(정답 수 ÷ 출제 수 × 100, 반올림), 정답 개수, 전체 해설을 확인합니다.
7. 같은 설정으로 재도전하거나 설정을 바꿀 수 있습니다. 답은 한 문제당 한 번만 제출됩니다. 시간 초과는 오답입니다.

사용 동사: 書く・泳ぐ・話す・待つ・飲む・遊ぶ・買う・行く・食べる・見る・起きる・する・来る.
새 동사는 추가하지 않았으며 오답 보기는 해당 동사의 잘못된 활용형입니다.

## 빌드와 테스트

Node.js 18 이상을 권장합니다. 게임 실행·단일 파일 빌드·단위 테스트는 npm 패키지 설치가 필요 없습니다.

```sh
npm run build
npm test
```

- `npm run build`: 원본을 합쳐 서버 없이 열리는 `dist/game.html`을 생성합니다.
- `npm test`: 확정된 13개 정답, 39개 오답 보기, 문제 수, 무작위 출제, 채점, 중복 응답, 시간 초과 상태를 검사합니다.
- `npm run test:browser`: 서버 실행 후 Playwright/Chromium으로 실제 UI를 검사합니다. 현재 클라우드 환경에는 둘 다 제공되어 있습니다.

다른 환경에서 브라우저 테스트를 실행하려면 Playwright와 Chromium을 준비하세요.

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run test:browser
```

시스템 Chromium은 `/usr/bin/chromium`이 있으면 자동 사용하며, 별도 경로는 `CHROMIUM_PATH`로 지정합니다.
기본 테스트 주소는 `http://127.0.0.1:8000`이며 `GAME_URL`로 바꿀 수 있습니다.
스크린샷은 `/tmp/te-game-start.png`, `/tmp/te-game-result.png`, `/tmp/te-game-mobile.png`에 저장합니다.

## 파일 구성

- `index.html`, `style.css`: 화면, 캐릭터, 반응형 스타일과 애니메이션
- `questions.js`: 확정된 13개 동사·보기·정답·해설
- `engine.js`: 출제, 상태 전환, 채점
- `app.js`: 설정, 타이머, 키보드, 게임·결과 화면
- `scripts/build.mjs`: 의존성 없는 단일 HTML 생성
- `tests/engine.test.js`, `scripts/browser-check.cjs`: 로직·실제 브라우저 검사

## 시작·다운로드 동작 보강

시작 버튼에 클릭 이벤트를 직접 연결하고, 선택된 라디오 값을 읽어 게임을 시작합니다. 단일 파일은 모듈 import 없이 일반 인라인 스크립트로 실행됩니다. 게임 내부 다운로드 버튼은 HTML Blob을 생성해 `.html` 파일로 저장합니다.

브라우저에서 13문제 정답 및 10문제 오답의 시작→결과 흐름, 데이터 연결, 타이머, 재도전과 다운로드 성공을 확인했습니다. 다운로드된 HTML을 HTTP로 다시 열어 같은 검사를 통과했습니다. 클라우드 Chromium의 파일 URL 접근 정책 때문에 `file://` 직접 열기는 검증하지 못했으며, 기존 시작 실패와 채팅 UI 다운로드 실패는 이 환경에서 재현하지 못했습니다.

## 휴대폰에서 실행하기

휴대폰 세로 화면에서는 보기가 한 줄에 하나씩 표시되고 버튼은 44px 이상 터치 영역을 가집니다. 가로 화면, 화면 확대와 노치 여백도 지원합니다. 히라가나(한자), 13개 동사와 규칙은 동일합니다.

HTML 첨부파일을 미리보기로 열면 휴대폰 파일 앱이 JavaScript 실행을 막을 수 있습니다. 가장 확실한 방법은 **PC와 휴대폰을 같은 Wi-Fi에 연결하고 브라우저로 접속**하는 것입니다.

1. PC에서 저장소 폴더를 열고 `python3 -m http.server 8000 --bind 0.0.0.0` 실행(Windows는 `py -m http.server 8000 --bind 0.0.0.0`도 가능).
2. PC 네트워크 설정에서 Wi-Fi의 로컬 IPv4 주소를 확인합니다(예: `192.168.0.10`).
3. 휴대폰 Safari/Chrome 주소창에 `http://192.168.0.10:8000/dist/game.html`처럼 **실제 PC 주소**를 입력합니다. `localhost`를 입력하면 PC로 연결되지 않습니다.
4. 연결이 안 되면 PC 방화벽에서 해당 서버의 개인 네트워크 접근 허용 여부와 공유기의 기기 간 통신 제한을 확인합니다. PC와 서버를 켜 둬야 합니다.

단일 HTML 파일만 PC에 저장했다면 그 파일이 있는 폴더에서 서버를 실행하고 주소 마지막에 저장한 파일명을 입력하세요. 공용 인터넷 주소로 배포한 상태는 아니므로 다른 Wi-Fi나 이동통신에서는 위 로컬 주소로 접속할 수 없습니다.

## GitHub Pages 배포

`.github/workflows/pages.yml`은 `main` 갱신 시 테스트와 단일 파일 빌드 후 GitHub Pages로 배포합니다.
저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정해야 합니다.
첫 설정 후 저장소 **Actions → Deploy game to GitHub Pages → Run workflow**로 실행할 수 있습니다.
정상 배포 후 예상 주소는 `https://pmk4341.github.io/japanese-te-form-game/`입니다.
워크플로 성공 및 공개 주소 확인 전에는 배포 완료로 간주하지 마세요.
